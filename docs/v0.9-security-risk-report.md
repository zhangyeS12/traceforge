# TraceForge v0.9: Security Risk Report

v0.9 adds a security-oriented risk report for each recorded run.

## New CLI

```powershell
traceforge risk <run_id>
traceforge risk <run_id> --json
```

The report scans:

- risky command markers such as destructive shell patterns
- sensitive-looking files such as `.env`, SSH keys, and credential files
- dependency and package-management files such as `pyproject.toml` and `package.json`
- CI/CD workflow files such as `.github/workflows/*.yml`
- broad file changes
- possible secret material in patch contents

## Dashboard

Run Detail now includes a **Risk Report** panel with overall risk level, finding counts, individual findings, and a review recommendation.

## Design note

This is not a replacement for a full sandbox or static analyzer. It is a lightweight review layer designed for AI coding agent runs, where the user wants a quick answer to: "Did this run touch anything risky?"
