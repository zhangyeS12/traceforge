# TraceForge v0.7.1 — Timeline Polish

This release tightens the black-box replay model introduced in v0.7.

## What changed

- `report.generated` now appears before `run.finished`.
- The core runner generates reports for both CLI and dashboard runs, so the event order is consistent.
- The dashboard shows the Timeline section before artifacts, making the replay narrative the first thing users see.
- `selftest` verifies the timeline ordering invariant.

## Why it matters

A black-box recorder should end a run only after all replay artifacts are ready. This makes the final timeline easier to explain in demos and more trustworthy for future AI-agent integrations.
