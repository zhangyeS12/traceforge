# TraceForge v1.0.0 — Stable Public Release

TraceForge v1.0.0 is the first stable public release of the local black-box recorder for command runs and AI coding agents.

## Included capabilities

- Local command recording
- Browser dashboard
- Timeline replay
- Run comparison
- Security risk reports
- JSON export and HTML reports
- `doctor`, `selftest`, `release-check`, and `version-check`
- GitHub Actions CI
- Security policy and issue templates
- Demo agent-run example

## Release checklist

Before publishing:

```bash
traceforge version-check
traceforge release-check
traceforge selftest
traceforge release-check --zip traceforge_v1_0.zip
```

Use Python package version `1.0.0` and Git tag `v1.0.0`.
