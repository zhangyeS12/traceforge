# TraceForge v0.5 — Selftest and release checks

v0.5 adds two public-readiness commands.

## `traceforge selftest`

Runs an end-to-end smoke test in a temporary Git repository:

1. Creates a temporary project.
2. Initializes Git and commits a baseline.
3. Initializes a TraceForge workspace.
4. Runs a command that modifies `app.py`.
5. Verifies that the command exits successfully.
6. Verifies that stdout/stderr/patch artifacts exist.
7. Verifies that SQLite saved the run, events, and changed files.
8. Generates an HTML report.
9. Exports `trace.json`.
10. Cleans the temporary project unless `--keep-temp` is used.

Useful commands:

```bash
traceforge selftest
traceforge selftest --json
traceforge selftest --keep-temp
```

## `traceforge release-check`

Validates source-tree and release-zip structure before publishing.

```bash
traceforge release-check
traceforge release-check --zip traceforge_v0_5.zip
```

This is meant to prevent packaging mistakes such as putting `pyproject.toml` at the wrong zip level.
