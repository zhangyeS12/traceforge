# TraceForge v1.2.0 — Accurate Change Attribution

This release strengthens TraceForge's core promise: show what the current command or agent run changed.

## Highlights

- Compares before/after dirty-file fingerprints to avoid attributing pre-existing unchanged dirty files to the current run.
- Generates run-attributed patches instead of blindly storing the final `git diff HEAD`.
- Includes untracked new file contents in `patch.diff`.
- Adds focused tests for dirty worktrees and untracked file capture.
- Refreshes README, SECURITY.md, release examples, and package metadata.
