# TraceForge v1.1.0 — Agent Adapter Layer

This release adds the first agent adapter layer. The goal is not to replace coding agents, but to wrap them so TraceForge can record and replay their behavior.

## New commands

```bash
traceforge agent list
traceforge agent doctor
traceforge agent run shell -- python modify_hello.py
traceforge agent run codex -- "fix the failing tests"
traceforge agent run claude -- "refactor this module"
traceforge agent run aider -- "add tests"
traceforge agent run opencode -- "implement the feature"
```

## Design

Adapters are intentionally thin. They turn a human task into a local process invocation; the existing TraceForge recorder still captures stdout, stderr, exit code, Git diff, changed files, risk report, and timeline events.

The `shell` adapter is a passthrough adapter for testing and for wrapping custom commands.

Custom adapters can be added later through `.traceforge/config.json`.
