# TraceForge v1.3.0 - First Run and Sharing

This release focuses on the first-time user experience and safer trace sharing.

## Highlights

- Restored the README demo GIF.
- Added a 30-second demo path for new users.
- Added clear "when to use it" and "what it is not" guidance.
- Added `traceforge export --redact` for best-effort masking of common secrets and local user paths.
- Added agent recipes for Codex, Claude Code, Aider, opencode, shell passthrough, and custom adapters.
- Added next-step CLI hints after `traceforge run`.
