# v0.8: Run Compare

TraceForge v0.8 adds first-class run comparison.

## Why this matters

AI coding agents are not deterministic. The same task can produce different patches, timelines, outputs, and failure modes across models or even across two runs of the same model.

Run Compare lets you inspect two recorded runs side by side so you can answer:

- Which run succeeded?
- Which run changed fewer files?
- Which run produced a larger patch?
- Which files were changed by both runs?
- Which files were unique to only one run?
- Which run generated more timeline events?

## CLI

```bash
traceforge compare <run_a> <run_b>
traceforge compare <run_a> <run_b> --json
```

`traceforge diff <run_a> <run_b>` remains available as a compatibility alias.

## Dashboard

The local dashboard now includes a **Compare runs** panel. Select Run A and Run B, then click **Compare** to see:

- exit code comparison
- duration delta
- changed-file delta
- event-count delta
- patch-size delta
- common files
- files only changed in A
- files only changed in B

## Public-readiness checks

`traceforge selftest` now verifies that compare payloads can be generated successfully.

`traceforge release-check` now checks that `traceforge/compare.py` is present in both local source trees and release archives.
