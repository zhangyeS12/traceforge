# Recording a short TraceForge demo GIF

A good GIF should show the product in under 20 seconds.

## Recommended flow

1. Run `traceforge dashboard`.
2. In the browser command box, run `python modify_hello.py`.
3. Click the new run.
4. Show **Patch**, **Timeline**, **Risk Report**, and **Compare** briefly.

## Windows tools

Recommended options:

- ScreenToGif
- ShareX
- OBS Studio, then convert to GIF or MP4

Save the result as:

```text
docs/assets/demo.gif
```

Then add it near the top of `README.md` after the static dashboard screenshot.
