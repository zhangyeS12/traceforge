# TraceForge v0.4 Dashboard Command Runner

Version 0.4 turns the dashboard from a read-only viewer into a local control surface.

## What changed

- The dashboard now has a **Run a command** panel.
- Users can type a command such as `python modify_hello.py` and click **Run Command**.
- The local server records the run using the same core engine as `traceforge run`.
- After the command finishes, the run list refreshes and the new run is selected automatically.
- A new local API endpoint is available: `POST /api/runs`.

## Why this matters

TraceForge still needs a CLI because it records local developer workflows, but a public-facing tool also needs a visual workflow. This release lets users start in the browser after launching the dashboard once.

## Current limitation

The v0.4 runner waits for the command to finish before updating the UI. A future version should add live streaming through Server-Sent Events or WebSockets.
