# TraceForge v1.0.0-rc1 — Public Release Candidate

This release candidate focuses on public readiness rather than new core features.

## Highlights

- Security policy documentation.
- GitHub issue templates.
- Installation and release documentation.
- Demo agent run example.
- Stronger release-check validation for public-readiness files.
- README updated for the release candidate.

## Why this matters

TraceForge now has a complete loop for early public use:

1. record a command run
2. replay it in the dashboard
3. inspect timeline events
4. compare runs
5. review risk findings
6. export/share trace artifacts
7. verify packaging with selftest and release-check

The next stable milestone is `v1.0.0`.
