# TraceForge v0.3.1 Dashboard Polish Notes

This release improves the local dashboard so it is easier to show in README screenshots and demos.

## Added

- Summary cards for total runs, success rate, failures, changed files, risky runs, and average duration.
- Run filters for All / Success / Failed / Changed / Risky.
- Patch-first run inspection with diff highlighting.
- Timeline styling with clearer event ordering.
- Copy button for the active artifact.

## Why this matters

The TraceForge core records command behavior, but a public developer tool also needs a visual surface that makes the value obvious within seconds. The v0.3.1 dashboard is still dependency-free, but starts to look and behave more like a real DevTools product.
