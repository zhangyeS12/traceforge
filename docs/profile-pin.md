# Pin TraceForge on your GitHub profile

Pinning the repository makes it visible immediately when someone opens your GitHub profile.

## Steps

1. Open your GitHub profile page.
2. Click **Customize your pins**.
3. Select `traceforge`.
4. Save.

Suggested profile wording:

> I build local-first developer tools for AI coding-agent observability. My current project is TraceForge, a black-box recorder for command runs and AI coding agents.
