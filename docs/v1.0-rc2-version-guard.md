# TraceForge v1.0.0-rc2 — Version Guard

This release candidate focuses on preventing release metadata drift.

## Why

TraceForge CI previously failed when `pyproject.toml`, `traceforge/__init__.py`, README badges, and release tags drifted apart.

## Changes

- `traceforge release-check` now validates package version, runtime version, README badge version, and CHANGELOG top version together.
- `traceforge version-check` provides a quick dedicated check before pushing or tagging.
- Release documentation now emphasizes updating all version surfaces before creating tags.
